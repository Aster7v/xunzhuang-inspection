# 巡桩问诊：智能移动巡检与异常预警

FishBot、ROS 2 与 MQTT 巡检项目的网站及只读数据接入程序。当前版本基于 Sites 第 4 版 `01e6a2246809f76cc7155cf2ead061c1effa9fbb`，并加入 MQTT 局域网出站网关与 ROS 2 只读桥。

## 目录

- `dist/index.html`：巡检网站前端。
- `backend/`：Python 后端、SQLite 存储与 API。
- `gateway/`：BIOT 出站网关和参数化 ROS 2 只读桥。
- `MQTT使用教程.md`：测试、配置和安全使用说明。

## 当前状态

云端网站部署在 <https://zhiri365.tech/fishbot/>，需要网站账号。代码仓库用于协作；GitHub Pages 只能提供静态文件，不能运行这里的 Python 后端，也不能单独完成 MQTT 数据接入。

## 在本机预览

克隆仓库后，在项目根目录运行：

```bash
python -m pip install -r backend/requirements.txt
python backend/server.py
```

默认监听 `127.0.0.1:8000`，用浏览器打开 `http://127.0.0.1:8000/`。未配置 MQTT 时，网站仍可打开并显示未配置状态。本地运行不连接线上数据库。

## 只读接口与数据

- `GET /api/status`：查看后端、MQTT 和网关状态。
- `GET /api/readings`：查看最近接收的数据记录。
- `POST /api/ingest`：仅供携带独立令牌的出站网关上传数据，令牌由运行环境配置，不放入源码。

生产环境通过 HTTPS 和代理访问保护上述接口；直接运行后端默认仅适合本地测试。数据和状态需要结合实际设备验证，阈值提醒默认关闭。

## 团队开发

先阅读 [团队协作流程](CONTRIBUTING.md)。成员在分支中开发并通过 Pull Request 请求审阅；GitHub Actions 会执行基础语法及后端测试。这些检查不等于硬件联调或生产部署验收。

已测试模拟 MQTT 消息到云端接收接口和断线重连。真实机器人、BIOT 和 ROS 2 消息仍需现场联调；没有启用远程运动控制。气体原始值不能当作气体浓度或安全判断。

账号、密码、令牌和数据库不属于本仓库，**不要提交或公开**。需要网页访问的成员向项目负责人私下索取网站账号；只有负责网关配置的成员才需要网关令牌。未经认证的 BIOT 仅限可信局域网，不得直接暴露公网。

本仓库更新不会自动改变阿里云运行环境；上线前需审查代码、测试并备份，使用现有服务的部署流程，保留回滚方案。避免修改同服务器上的其他项目。

仓库后端包含数据库连接释放的改进；该改进目前仅在仓库中，尚未部署到阿里云。
